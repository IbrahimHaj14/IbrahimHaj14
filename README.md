## Featured projects

### [AI-Assisted Versioned Text Editor](https://github.com/IbrahimHaj14/Versioned-AI-Text-Editor)
**React · TypeScript · FastAPI · Python · Pydantic · SQLite · OpenAI API · Docker**

A full-stack rich-text editor where users can make natural-language edits through an AI assistant while maintaining document versions.

Built the versioning workflow and AI editing pipeline, including structured AI responses, server-side sanitisation, persistence, REST APIs and automated tests.

### [Inventory Reconciliation Agent](https://github.com/IbrahimHaj14/inventory-reconciliation-agent)
**Python · Pydantic · Async APIs · State machines · Testing · Hypothesis**

A reliability-focused agent for reconciling conflicting inventory data from multiple sources that may be stale, slow or unavailable.

The decision core is **deterministic and auditable**: source trust, freshness, latency, reliability and corroboration are scored explicitly, while the optional LLM is restricted to the presentation layer. The system escalates when evidence is insufficient instead of fabricating an answer.

### [WHO TB Data Insights](https://github.com/IbrahimHaj14/who-tb-data-insights)
**Python · Pandas · SQLAlchemy · SQLite · Streamlit · Plotly**

An end-to-end data platform for exploring WHO tuberculosis treatment outcomes across **217 countries, 698 indicators and 136,000+ data points**.

Includes a complete ETL pipeline, validation and cleaning, relational schema transformation, database upserts, and an interactive dashboard for filtering and exploring trends.
