## Some of my projects

### [AI-Assisted Versioned Text Editor](https://github.com/IbrahimHaj14/Versioned-AI-Text-Editor)

A full-stack text editor with an AI assistant that can make natural-language edits while keeping track of document versions.

**React · TypeScript · FastAPI · Python · Pydantic · SQLite · OpenAI API · Docker**

### [Inventory Reconciliation Agent](https://github.com/IbrahimHaj14/inventory-reconciliation-agent)

An agent that reconciles inventory data from different sources when the data can be stale, slow or contradictory.

I focused on making the decision process reliable and easy to audit, using explicit scoring and validation rather than relying on an LLM to make the final decision.

**Python · Pydantic · APIs · Agent Workflows · Testing**

### [WHO TB Data Insights](https://github.com/IbrahimHaj14/who-tb-data-insights)

A data pipeline and interactive dashboard for exploring WHO tuberculosis treatment outcomes across 217 countries, 698 indicators and 136,000+ data points.

The project covers the full process from cleaning and transforming the data to storing it in a relational database and presenting it through an interactive dashboard.

**Python · Pandas · SQLAlchemy · SQLite · Streamlit · Plotly**
